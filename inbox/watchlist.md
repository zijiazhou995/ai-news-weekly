# 每周人工巡检清单

这些来源通常没有稳定 RSS，或对自动抓取不友好。每周四生成草稿前，建议快速扫一遍；看到合适资讯后，用 `python3 weekly_ai_news.py add` 加到 `inbox/manual_items.jsonl`。

## 阿里/电商优先

- 阿里云官网新闻、阿里云开发者社区、阿里云微信公众号
- 通义、魔搭社区、阿里云百炼相关公告
- 淘宝、天猫、淘宝天猫商家后台公告
- 1688、AliExpress、Lazada 官方动态
- 支付宝开放平台、支付宝商家平台
- 钉钉、夸克、菜鸟官方动态

## 国内大厂

- 微信开放平台、微信公众平台、微信小程序公告
- 腾讯云、企业微信、腾讯混元官方动态
- 百度智能云、百度搜索、百度地图、百度网盘官方动态
- 火山引擎、飞书、豆包、剪映官方动态
- 京东、拼多多、美团、小红书、快手官方动态

## 海外大厂/产品公司

- Google Blog、Google Workspace、Google Cloud Blog
- Microsoft Blog、Microsoft 365、Azure Blog
- Amazon / AWS Blog
- Meta AI Blog
- Adobe Blog
- Shopify、Salesforce、Canva、Notion、Slack、Zoom 官方 Blog

## 手动补充判断标准

- 是产品、工具、功能、开放接入、商家能力、工作台、插件、智能体、应用落地。
- 优先阿里、电商、商家经营、客服、营销、导购、支付、零售、供应链。
- 不加入纯模型更新、参数升级、榜单评测、融资、人事、观点文章。
